How to use TfL Status Simplified

This app translates complex TfL updates into clear, visual route maps so you can quickly see which stations are delayed or closed.

🗺️ Network Map Tab (Landing Page)

An interactive grid overview of the entire network. Displays summaries like "✓ Normal service" or "⚠️ Part of line affected". Tap any line to view its individual visual route map.

🔴 Live Status Tab

Shows all Tube, Overground, DLR, and Elizabeth Line routes sorted by service health.

  • 🔴 Red: Section closed or no service.
  • 🟠 Orange: Severe delays across the line.
  • 🟡 Yellow: Minor delays or reduced service.
  • 🟢 Green: Good service operating normally.
  • 🗺️ Visual Map: Tap "Show visual map" under any disrupted line to view a vertical tube map highlighting closed stations.
  • ⭐ Favorites: Tap the star next to a line to pin it. Check "Favorites only" to view your daily routes quickly.

⏱️ Live Timetable Tab

Type any London station name in the search bar to find live departures for all platforms and serving lines.
